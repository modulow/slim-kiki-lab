# Slim Kiki Lab

Static GitHub Pages training surface for Slim Kiki.

## What a report contains

The **Report to Wiki Kiwi** button opens a prefilled GitHub issue with:

- the exact user question;
- the answer displayed by the lab;
- the current structured plan (scope, measure, calculation, grouping, result shape);
- a required field for the expected correction.

No user credentials, browser history or hidden FLUX content are included.

## Publishing

The included GitHub Actions workflow deploys `docs/slim-kiki-lab` to GitHub Pages on each push to `main`. In the repository settings, set **Pages → Source** to **GitHub Actions** once.
